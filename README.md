# Controle de Produtos CLI

Sistema de gerenciamento de estoque em linha de comando (CLI) desenvolvido em Python. O aplicativo permite cadastrar, listar, buscar e remover produtos diretamente pelo terminal com validação de dados e interface interativa.

---

## 🚀 Funcionalidades

- **Cadastrar Produtos:** Permite adicionar itens informando nome, preço e quantidade.
- **Listar e Remover:** Exibe todos os produtos cadastrados com seus respectivos índices e permite a remoção individual.
- **Buscar Produto:** Localiza um produto específico pelo nome (busca insensível a maiúsculas/minúsculas).
- **Tratamento de Erros:** Valida entradas de usuário evitando valores negativos, tipos de dados incorretos e falhas de digitação (como conversão automática de vírgula para ponto no preço).
- **Interface Colorida:** Utiliza códigos ANSI para destaque visual de mensagens de sucesso, alerta e erro no terminal.

---

## 🛠️ Tecnologias Utilizadas

- **Python** (Lógica principal e estruturas de dados em memória utilizando dicionários e listas)
